RPCM_3I_ATLAS_Simulation_Package

This package contains:
1. RPCM_3I_ATLAS_Simulation.ipynb - Jupyter Notebook simulation
2. README_RPCM.txt - Instructions

Run instructions:
1. Open in Jupyter Notebook or Google Colab.
2. Run all cells to generate plasma clustering visuals.
3. The simulation mimics interstellar comet 3I/ATLAS plasma-dust dynamics.
4. Optional: Export animation as .gif or .mp4 for Grok/X sharing.
